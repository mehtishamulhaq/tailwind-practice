# 06 — Flexbox

## Goal
Arrange items in a row using flexbox.

## Concepts
- Flex container
- Gap
- Justify content (main axis distribution)
- Flex grow

## Requirements
- [ ] Place Item A, B and C horizontally
- [ ] Add space between them with a gap
- [ ] Push "Logo" and "Menu" to opposite ends
- [ ] Bonus: make the middle item grow to fill the space

## What to remember
- Flex utilities go on the **parent**; the children become flex items.
- The default direction is a row.
- Gap adds consistent space between items without margins.
- Justify controls distribution along the main axis (horizontal in a row).
- Grow/shrink utilities go on the **child**.

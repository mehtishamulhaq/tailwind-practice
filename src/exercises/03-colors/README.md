# 03 — Colors

## Goal
Use Tailwind's color palette for backgrounds and text.

## Concepts
- Background color
- Text color
- Color shades
- Opacity modifier (`/`)

## Requirements
- [ ] Give box one a background color
- [ ] Change its text color so it stays readable
- [ ] Give box two a different background and text color
- [ ] Bonus: give box three a semi-transparent background

## What to remember
- The same color names work for backgrounds, text, borders and more — only the prefix changes.
- Dark background → light text, and vice versa. Always check contrast.
- Add `/` plus a number after any color to set its opacity.
- Padding helps you actually see a background color.

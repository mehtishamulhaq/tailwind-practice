# 01 — Text

## Goal
Turn plain, unstyled text into a clear heading and readable paragraphs.

## Concepts
- Font size
- Font weight
- Text alignment
- Text color
- Font style, text decoration, text transform
- Line height

## Requirements
- [ ] Make the heading large
- [ ] Make it bold
- [ ] Center the text
- [ ] Change the text color
- [ ] Bonus: smaller, lighter-gray paragraph with more line height
- [ ] Bonus: italic, underlined and uppercase words

## What to remember
- Tailwind's reset (Preflight) removes default heading sizes — an `<h1>` looks like normal text until you style it.
- Size, weight, alignment and color are separate utilities. You combine them.
- Color utilities follow a `property-color-shade` pattern, with shades from 50 (lightest) to 950 (darkest).

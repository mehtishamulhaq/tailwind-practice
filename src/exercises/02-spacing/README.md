# 02 — Spacing

## Goal
Give elements room using padding, margin and "space between" utilities.

## Concepts
- Padding (all sides, x/y axes, single sides)
- Margin
- Space between children
- The spacing scale

## Requirements
- [ ] Add padding to the container
- [ ] Add margin between the heading and paragraph
- [ ] Add vertical spacing between the list items — using one class on the `<ul>`
- [ ] Add horizontal spacing between the two buttons

## What to remember
- Padding is space *inside* an element; margin is space *outside* it.
- `x` means left + right, `y` means top + bottom; `t`, `r`, `b`, `l` target one side.
- The spacing scale is based on 0.25rem steps: the number × 4 = pixels (roughly).
- "Space between" utilities go on the *parent* and space out its children.

# 05 — Width & Height

## Goal
Control the size of elements.

## Concepts
- Fixed width / height (spacing scale)
- Percentage / fraction widths
- Full width
- Max width

## Requirements
- [ ] Give box one a fixed width
- [ ] Make box two full width
- [ ] Give box three a fixed height
- [ ] Make box four half the width of its parent
- [ ] Bonus: limit the paragraph's max width

## What to remember
- Width and height use the same spacing scale as padding and margin.
- Fractions (like halves and thirds) give percentage widths.
- `full` means 100% of the parent; `screen` means the viewport.
- Max width is great for readable text; it lets content shrink but not grow past a limit.
- Add a background color while experimenting so you can see the size.

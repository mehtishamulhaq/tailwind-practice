# 04 — Borders

## Goal
Outline and shape boxes with borders, rounded corners and shadows.

## Concepts
- Border width and color
- Single-side borders
- Border radius
- Box shadow

## Requirements
- [ ] Add a border to box one
- [ ] Round the corners of box two
- [ ] Add a shadow to box three
- [ ] Make the "JD" avatar a perfect circle (it needs equal width and height)
- [ ] Bonus: a colored border on only the left side

## What to remember
- A bare border utility gives a 1px border; add a number for thicker ones.
- Border color is a separate class from border width.
- Rounded corners are only visible if the element has a border, background or shadow.
- A circle = equal width + height + full rounding.

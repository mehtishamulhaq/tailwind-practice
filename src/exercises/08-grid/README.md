# 08 — Grid

## Goal
Lay items out in a grid of columns.

## Concepts
- Grid container
- Grid template columns
- Gap
- Column span

## Requirements
- [ ] Turn the first container into a 3-column grid
- [ ] Add gaps between items
- [ ] Bonus: make the "Wide" item span 2 columns

## What to remember
- Grid utilities go on the parent; span utilities go on the child.
- The columns utility creates equal-width columns.
- The same gap utility works for both flex and grid.
- Use flex for one direction (a row *or* a column); use grid for rows *and* columns.

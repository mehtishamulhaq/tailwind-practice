# 12 — Card

## Goal
Combine everything so far into a simple content card.

## Concepts
- Sizing (max width)
- Background, border, rounded corners, shadow
- Padding and spacing
- Typography
- Flex for the tag row
- Button states

## Requirements
- [ ] Limit the card width and center it on the page
- [ ] Give the card a background, rounded corners and a border or shadow
- [ ] Give the image placeholder a height and background color
- [ ] Add padding to the content area
- [ ] Style the meta line small and muted, the title large and bold
- [ ] Space the elements vertically
- [ ] Put the tags in a row with gaps, and style each tag as a small pill
- [ ] Style the "Read more" button with a hover state

## What to remember
- Build it up in layers: size → surface → spacing → typography → details.
- Rounded corners on the card won't clip the image unless the overflow is hidden.
- Consistent spacing values make a design look intentional.

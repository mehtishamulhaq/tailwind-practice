# 13 — Form

## Goal
Style a sign-up form so it's clear and easy to use.

## Concepts
- Label styling / block display
- Input borders, padding, rounded corners
- Spacing between fields
- Focus styles on inputs
- Placeholder styling
- Button styling

## Requirements
- [ ] Limit the form width
- [ ] Make labels sit above inputs and look like labels
- [ ] Style inputs: border, padding, rounded, full width
- [ ] Add spacing between the fields
- [ ] Add a visible focus style to inputs (border and/or ring color change)
- [ ] Style the submit button, including hover
- [ ] Bonus: put the checkbox and its label in a row
- [ ] Bonus: style the hint/error text small and red

## What to remember
- Inputs have almost no styling after Preflight — you must add a border to see them.
- Labels are inline by default; make them block (or use a flex column) to stack them.
- Focus styles on inputs are just as important as on buttons.
- There's a `placeholder:` variant for styling placeholder text.

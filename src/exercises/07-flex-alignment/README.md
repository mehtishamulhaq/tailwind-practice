# 07 — Flex Alignment

## Goal
Center things and control alignment on both axes.

## Concepts
- Flex direction (row / column)
- Justify content (main axis)
- Align items (cross axis)
- Why height matters for vertical centering

## Requirements
- [ ] Center "Center me" vertically in a tall box
- [ ] Center it horizontally too
- [ ] Make the "Row" group a row and the "Column" group a column
- [ ] Align the different-height items to the bottom

## What to remember
- **Justify** = main axis, **items** = cross axis.
- Switching to a column swaps the axes: justify becomes vertical.
- You can't see vertical centering unless the container is taller than its content.
- Flex + center on both axes is the classic way to center anything.
